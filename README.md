## ⚙️ 无人值守流水线

```text
06:17  GitHub Actions     抓 arXiv → 打分 → 生成中文日报 → 提交（云端，不受本机开关机影响）
07:05  Windows 计划任务    检查当日是否已有产出 → 缺则补跑 → 同步三站辅助平台
07:05  ⏰ 定时汇报         汇总当日结果并推送通知
├─ 失败降级：抓取全挂 → 不写空日报；推送失败 → 自动重试；错过时间 → 开机自动补跑
└─ 凭据安全：凭据只存本机凭据管理器，自动化全程不弹窗、不交互
```
