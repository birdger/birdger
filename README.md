### 📡 每日自动更新的科研雷达

[**daily-arxiv-digest**](https://github.com/birdger/daily-arxiv-digest) —— 每天自动抓取 arXiv 的 `cs.IR` / `cs.CL` / `cs.CV` / `cs.MM` / `cs.LG`，
按关键词加权打分，生成一份中文论文日报并自动提交。零成本跑在 GitHub Actions 上。

[![Daily arXiv Digest](https://github.com/birdger/daily-arxiv-digest/actions/workflows/daily.yml/badge.svg)](https://github.com/birdger/daily-arxiv-digest/actions/workflows/daily.yml)
